(official V2 `ESP-IDF/11_FactoryProgram`) as the baseline. A clone of that
repository (commit `1c157e6e8e68b89fd4dc400f46bf1724cb64a57e`, "first commit",
2026-06-09) was compared with this repository by SHA-256 (line endings
normalised). Its `LICENSE` file is the Apache License, Version 2.0 (licence
text A; it is byte-identical to the `LICENSE` file this repository carried
